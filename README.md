# Installation

### Terminal Install
```
git clone https://github.com/MickyMouse101/MiniAsteroidGame.git
```

# UV Install & Setup

### Linux & macOS
```
curl -LsSf https://astral.sh/uv/install.sh | sh
```
### Windows
```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
### PyPi
```
pipx install uv
```

# Game Setup

```
uv run main.py
```
